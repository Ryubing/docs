Firmware
=======
- Launch Homebrew Menu and open NXDumpTool (nxdt_rw_poc).
  ![2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/hbmenu_opennxdt.jpg?raw=true)

- Select `dump system update`
  ![dump_system_update](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/ndxt_dumpsystemupdate.jpg?raw=true)

- Select `start dump`
  ![start_system_update_dump](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_startfwdump.jpg?raw=true)

- If you have setup [USB dumping](../usb-dumping) you can dump straight to a PC if you `set output storage`: to `usb host (pc)`
- If you set output to `usb host (PC)`, make sure nxdt_host is open on your PC, then connect your Switch. Dumping will begin.
