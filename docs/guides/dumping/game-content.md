Base Game (NSP-Eshop)
=======
- Launch Homebrew Menu and open NXDumpTool (nxdt_rw_poc).
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/hbmenu_opennxdt.jpg?raw=true)

- Select `user titles menu`
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_usertitlesmenu.jpg?raw=true)

- Find the game you want to dump and select it.
  - Select `nsp dump options` --> `dump base application`

  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_nspdumpoptions.jpg?raw=true)
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_dumpbaseapp.jpg?raw=true)

- If you have setup [USB dumping](../usb-dumping) you can dump straight to a PC if you `set output storage`: to `usb host (pc)`
- Select `start nsp dump`
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_startnspdump.jpg?raw=true)
  
- If you set output to `usb host (PC)`, make sure nxdt_host is open on your PC, then connect your Switch. Dumping will begin.

  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/hbmenu_opennxdt.jpg?raw=true)

- Select `gamecard menu`
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_gamecardmenu.jpg?raw=true)

- Select `dump gamecard image (xci)`

- Select `start xci dump`
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_startxcidump.jpg?raw=true)

- If you set output to `usb host (PC)`, make sure nxdt_host is open on your PC, then connect your Switch. Dumping will begin.

Updates & DLC
=======
- Launch Homebrew Menu and open NXDumpTool (nxdt_rw_poc).
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/hbmenu_opennxdt.jpg?raw=true)

- Select `user titles menu`
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_usertitlesmenu.jpg?raw=true)

- Find the game you want to dump and select it.
- Select `dump update` to dump an update, or `dump dlc` to dump DLC for the game.
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_dumpupdate.jpg?raw=true)
  
- If dumping DLC, press `L/ZL` or `R/ZR` to change the selected DLC title to dump.
- If you have setup [USB dumping](../usb-dumping) you can dump straight to a PC if you `set output storage`: to `usb host (pc)`
- Select `start nsp dump`

  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_startnspdump-update.jpg?raw=true)
  ![](https://github.com/Ryubing/Assets/blob/main/docs/guides/dumping/nxdt_startnspdump-dlc.jpg?raw=true)
- If you set output to `usb host (PC)`, make sure nxdt_host is open on your PC, then connect your Switch. Dumping will begin.
