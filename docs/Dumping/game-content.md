Base Game (NSP-Eshop)
=======
- Launch Homebrew Menu and open NXDumpTool (nxdt_rw_poc).

  ![2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8](uploads/d0249fbc0fdcb3cff9eccc9a164698db/2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
- Select `user titles menu`

  ![2025040903482500-DB1426D1DFD034027CECDE9C2DD914B8](uploads/d46b7abdad2ade8d5bc8e71ec39c49f1/2025040903482500-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
- Find the game you want to dump and select it.
- Select `nsp dump options` --> `dump base application`

  ![2025040903490700-DB1426D1DFD034027CECDE9C2DD914B8](uploads/895636ffbc5351aa13b4a7725ed382c0/2025040903490700-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
![2025040903491100-DB1426D1DFD034027CECDE9C2DD914B8](uploads/d5a3dbe4c0c6bbce58544f6079483705/2025040903491100-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
- If you have setup [USB-dumping](https://git.ryujinx.app/ryubing/ryujinx/-/wikis/Dumping/USB-Dumping) you can dump straight to a PC if you `set output storage`: to `usb host (pc)`
- Select `start nsp dump`

  ![2025040903491400-DB1426D1DFD034027CECDE9C2DD914B8](uploads/fffa4a33f12bc99fd245aa26db0b622e/2025040903491400-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
- If you set output to `usb host (PC)`, make sure nxdt_host is open on your PC, then connect your Switch. Dumping will begin.

Base Game (XCI-cartridge)
=======
- Launch Homebrew Menu and open NXDumpTool (nxdt_rw_poc).


  ![2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8](uploads/d0249fbc0fdcb3cff9eccc9a164698db/2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}

Updates & DLC
=======
- Launch Homebrew Menu and open NXDumpTool (nxdt_rw_poc).


  ![2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8](uploads/d0249fbc0fdcb3cff9eccc9a164698db/2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
- Select `user titles menu`

  ![2025040903482500-DB1426D1DFD034027CECDE9C2DD914B8](uploads/2e571a92c1dc93c4999ba9a7e05af921/2025040903482500-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
- Find the game you want to dump and select it.
- Select `dump update` to dump an update, or `dump dlc` to dump DLC for the game.

  ![update](uploads/3ef5102d3bbef2a7be0d5f76cf140a21/update.jpg){width=25%}
- If dumping DLC, press `L/ZL` or `R/ZR` to change the selected DLC title to dump.
- If you have setup [USB-dumping](https://git.ryujinx.app/ryubing/ryujinx/-/wikis/Dumping/USB-Dumping) you can dump straight to a PC if you `set output storage`: to `usb host (pc)`
- Select `start nsp dump`

  ![start_nsp_dump_-_update](uploads/89f669695e513472fecc853c37c657dd/start_nsp_dump_-_update.jpg){width=25%}
![start_nsp_dump_-_dlc](uploads/a92cd04d5f32f000bf7ddfff91250a93/start_nsp_dump_-_dlc.jpg){width=25%}
- If you set output to `usb host (PC)`, make sure nxdt_host is open on your PC, then connect your Switch. Dumping will begin.
