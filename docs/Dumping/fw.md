Firmware
=======
- Launch Homebrew Menu and open NXDumpTool (nxdt_rw_poc).

  ![2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8](uploads/d0249fbc0fdcb3cff9eccc9a164698db/2025040903470900-DB1426D1DFD034027CECDE9C2DD914B8.jpg){width=25%}
- Select `dump system update`

  ![dump_system_update](uploads/1d3fc40d7423ec7af5ea71b56c016a24/dump_system_update.jpg){width=25%}
- Select `start dump`

  ![start_system_update_dump](uploads/0b0455bd0e3b22d9ee70bf04377399c7/start_system_update_dump.jpg){width=25%}
- If you have setup [USB-dumping](https://git.ryujinx.app/ryubing/ryujinx/-/wikis/Dumping/USB-Dumping) you can dump straight to a PC if you `set output storage`: to `usb host (pc)`
- If you set output to `usb host (PC)`, make sure nxdt_host is open on your PC, then connect your Switch. Dumping will begin.
